# Exploratory testing with ChatGPT

This repository contains the artifacts related to the article "Leveraging Generative AI for Exploratory Testing: Insights from an Empirical Study with ChatGPT". These artifacts include scripts, generated test suites and other resources that support the study.

## About This Study

This study explores the use of ChatGPT for generating exploratory test suites. The goal was to evaluate how effective ChatGPT is at creating test cases that can help manual testers in their exploratory testing process.

ChatGPT's ability to generate test suites was evaluated for 5 systems and the AI-generated test cases were compared with those created manually by human testers. Feedback was also collected from testers to assess the quality and applicability of the test suites generated by ChatGPT.
